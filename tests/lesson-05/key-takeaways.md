# Git
## Undo action
- git restore --staged <file_name>: restore file cụ thể
- git restore --staged . : restore all files
- git reset HEAD~1: reset 1 commit
- git reset HEAD~N: reset N commit 


## Branching model
- git branch: danh sách nhánh
- git branch <ten_nhanh>: tạo nhánh mới
- git checkout <ten_nhanh>: chuyển sang nhánh mới
- git checkout -b <ten_nhanh>: taoh và chuyển sang nhánh mới
- git branch -D <ten_nhanh>: xóa nhánh
